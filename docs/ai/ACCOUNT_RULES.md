# Account-wide working rules

These apply to EVERY project, every working directory and every chat on this
account, not just the one they were first stated in.

## Long jobs: finish them, across usage windows

When given a body of work (tasks, updates, tests), keep going until it is
actually finished. Do not stop early to check in, and do not hand back a
half-done job.

**The 5-hour usage limit is a pause, not a finish line.**

- Watch the 5-hour usage limit as you work.
- When it reaches about **90%**, stop cleanly. Do not start anything new that
  you cannot finish inside the remaining budget.
- Before pausing, leave the work in a resumable state: commit what is done,
  update the project's handoff or state document, and say plainly what is
  finished, what is not, and what the exact next step is.
- Then wait for the limit to reset. When it does, resume and continue in the
  same rhythm.
- Repeat for as many windows as the work needs.

Stopping cleanly at ~90% matters more than squeezing in one more edit: being
cut off mid-change leaves broken files and a lost thread.

## Arabic writing

Arabic is the owner's working language. Write Modern Standard Arabic, and never
begin an Arabic sentence or a line with a Latin word (a URL, a product name, an
email, `DNS`, `MX`). Right-to-left text garbles when a line starts with Latin
characters. Put an Arabic word first, always.

Avoid the em-dash in Arabic prose; use a comma, a colon, or a hyphen.
